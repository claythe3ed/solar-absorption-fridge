# Solar Absorption Fridge

Project for building a solar-powered ammonia-water absorption refrigerator for a single household.

## Structure
- docs: books, patents, datasheets
- data: property data and measurements
- src: Python source code
- sim: simulation models and results
- cad: engineering drawings
- scripts: helper scripts
- results: plots and logs
- notes: daily notes

## Run
pip install -r requirements.txt
python src/main.py
