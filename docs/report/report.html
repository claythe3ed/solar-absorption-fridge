01 / Design Overview

A solar fridge without a compressor

Absorption refrigeration replaces mechanical work with heat. The NH3-H2O pair, first used in the 1850s, is proven — but difficult to model with modern libraries.

200WCooling 150LCold box 0.424COP 1.59m2Collector

Purpose

Build a household-scale refrigerator that runs entirely on solar heat, with no mechanical compressor and no moving parts. Target: off-grid communities in Sudan where grid electricity is unreliable.

The four-component cycle

Solar heat drives ammonia out of a rich NH3-H2O solution in the generator. The vapor condenses in the condenser and flashes into the evaporator, where it absorbs heat from the cold box. It then returns to the absorber where poor solution from the generator reabsorbs it. No compressor — pressure difference is maintained by heat and gravity alone.

Key design decision NH3-H2O was chosen over LiBr-H2O because it can reach -15 C. LiBr-H2O cannot go below 0 C and requires vacuum seals.
02 / Thermodynamic Model

Working around CoolProp's binary pair gap

CoolProp does not include a binary interaction pair for NH3-H2O. This project documents the gap and provides a validated alternative.

The gap

CoolProp's HEOS backend requires departure-function parameters for each binary pair. For NH3-H2O, those parameters have never been fitted. A direct call fails with:

ValueError: Could not match the binary pair [7664-41-7, 7732-18-5]

This is a data gap, not an implementation bug. The infrastructure exists but the fit has never been supplied. See CoolProp Issue #341, open since 2014.
