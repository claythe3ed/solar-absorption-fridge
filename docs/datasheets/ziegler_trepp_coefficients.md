# Ziegler-Trepp Coefficients for NH3-H2O Mixture

Cross-validated from:
- Kherris et al. (2013), Thermal Science, 17(3):891-902
- Sadhukhan et al., Int. Centre for Applied Thermodynamics, 15(3)
- Original source: Ziegler & Trepp (1984), Int. J. Refrigeration, 7(2):101-106

## Reference State
- R = 8.314 kJ/(kmol·K)
- T_B = 100 K
- P_B = 10 bar  (NOTE: Kherris uses 10 bar, Sadhukhan uses 1 MPa = 10 bar - SAME)

## Reduced Variables
- T_r = T / T_B
- P_r = P / P_B
- G_r = G / (R·T_B)
- H_r = H / (R·T_B)
- S_r = S / R
- V_r = V·P_B / (R·T_B)
